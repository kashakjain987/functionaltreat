## Project Folder

Main Python file:

`functionaltreat.py`

## About the Project

This is a simple Python program used to enter, analyze, filter, and sort
data.

The program works with a 1D list of numbers. It uses a menu so the user
can easily select what they want to do.

## Features

The program has these options:

1.  Input Data
2.  Display Data Summary
3.  Calculate Factorial
4.  Filter Data by Threshold
5.  Sort Data
6.  Display Dataset Statistics
7.  Exit Program
